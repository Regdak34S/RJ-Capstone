# Candidate A - Content Planning & Organization Tool



## 1. Problem
**What real problem does this address?**  
One problem I have with content creation is keeping all of my ideas, scripts, assets, and plans organized in one place. When I work on videos or other content, I can have an idea in one place, the script somewhere else, and the media or other resources in different folders. This can make it harder to keep track of what I have already finished and what still needs to be done.

**Who experiences the problem?**  
Content creators, students, and people who create videos or other digital projects can experience this problem. I especially see it applying to someone like me because I use technology and AI tools to help create content and sometimes have several parts of a project being worked on at the same time.

**What situation causes the problem?**  
The problem happens when I start creating content without having a clear plan for the different parts of the project. For example, I may have an idea for a video but then have to switch between writing the script, finding assets, editing, and keeping track of what still needs to be completed.

**What goes wrong?**  
I can lose track of my progress or spend extra time looking for information and figuring out what I should work on next. Instead of focusing on creating the actual content, I spend time organizing the project.

## 2. Cost and current behavior
**What does the problem cost, using a real number?**  
For my own project, I would measure the cost by the amount of time I spend organizing or looking for content instead of creating it. My current estimate based on my own experience is 2 hours per project. I would determine this by recording the time I spend organizing files, finding ideas, rewriting plans, and preparing content.

**What do people currently do instead?**  
People can use folders, notes apps, spreadsheets, documents, or project-management tools to organize their content. I currently use a combination of folders, documents, and different software to keep track of my work.

**Why isn't that workaround good enough?**  
These tools can help, but they are not specifically designed around my content-creation process. I may still have to move between different programs and remember where everything is located.

## 3. Proposed project
**What would your project actually need to do?**  
The project would provide a simple workspace where I could create a content project, organize ideas, create a basic content plan, keep track of scripts and assets, and mark different parts of the project as completed. The goal would be to make the content-creation process easier to follow without trying to build a full professional editing program.

## 4. Difference
**What makes this idea different from the other two?**  
This idea focuses mainly on planning and organization. The main goal is to help me manage the content-creation process rather than automatically create the content itself or focus mainly on editing.

## 5. Dependencies
**What outside services, APIs, software, or data would it depend on?**  
The project could use normal web-development software and local file storage. If I decide to add AI assistance, it could depend on an AI API, but I would prefer to keep the first version independent of an external AI service so the project is easier to build and test.

## 6. Feasibility
**What could make the idea impossible or too large for this course?**  
The biggest problem would be trying to turn it into a complete content-management platform. Adding accounts, cloud storage, collaboration, advanced AI, video editing, or integrations with many other services could make the project too large. I would need to keep the project focused on basic planning and organization.

## 7. Setup
**What is the best way to set up this idea to get ready for the project?**  
I would start by defining the basic content-creation workflow I personally use. Then I would identify the most important information that needs to be stored, such as project ideas, scripts, assets, and progress. After that, I would create a simple prototype and test whether I can use it to organize one real content project from beginning to end.
